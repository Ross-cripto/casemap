# Example: Next.js Commerce

The use cases of [Next.js Commerce](https://github.com/vercel/commerce), a Shopify storefront, written by a coding agent following the casemap skill (app commit f7521d5). The flows describe the app's behaviour in casemap's words; Next.js Commerce is MIT licensed.

Open [`docs/flows/`](docs/flows) to see the map by activity; GitHub renders each flow's diagram. Or explore it in the terminal:

```sh
cd examples/commerce
casemap          # browse the use cases
casemap map      # the map by activity
casemap check    # validate the catalog
```

The original flows tie their steps to the app's code with `%% @code` anchors. That code is not in this repository, so the anchors are removed here. casemap's own [`docs/flows/`](../../docs/flows) shows anchors at work.
